# PRINCIPIA — BIOINSTRUMENTATION PROJECT

PRINCIPIA is a web-based interface developed as part of a school
research project involving an IV Weight Monitor.

The project provides an experimental interface for monitoring IV fluid
weight, remaining fluid percentage, and bag count using data retrieved
from ThingSpeak.
